## 三、装配方式

在目标 profile 的 `package.json`（`$DSH_HOME/profiles/<name>/package.json`）：

```jsonc
{
  "dependencies": {
    "@deepseek-ai/dsh-memory-harness": "link:/abs/path/dsh-memory-harness",
    "@deepseek-ai/dsh-skill-forge": "link:/abs/path/dsh-skill-forge",
    "@deepseek-ai/dsh-review-core": "link:/abs/path/dsh-review-core"
  },
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-headless", "@deepseek-ai/dsh-memory-harness", "@deepseek-ai/dsh-skill-forge"]
    }
  }
}
```

约束：memory 插件须装配在 `agent-instructions` / `tool-skill` 之后（注入顺序 baseline→catalog→memory，D15/D21）；review 三路输出②需组合层 `ctx.provide('memoryStore', store)` 接线。

## 四、配置项速查

### dsh-memory-harness
| 字段 | 默认 | 说明 |
|---|---|---|
| `memoryLimit` | 2200 | MEMORY 容量上限（条目内容字符数） |
| `userLimit` | 1375 | USER 容量上限（M1b 启用） |
| `includeSoul` | true | 注入 SOUL 人格 section（soul -200 / core -90） |
| `includeSnapshot` | true | 注入 MEMORY 快照消息 |
| `writeApproval` | false | 门控（D7 取消默认） |
| `homePath` / `profile` | $DSH_HOME / '' | 档案解析（配置档案 > 启动 profile > default） |

### dsh-skill-forge
| 字段 | 默认 | 说明 |
|---|---|---|
| `defaultRoot` | 'user' | 技能扫描根 |
| `maxSkillBytes` | 32768 | 单 SKILL.md 字节上限 |
| `homePath` / `skillRoot` / `stagedDir` | 推导 | 根/staged 覆盖 |
| `reviewEnabled` | true | 后台 review 开关 |
| `reviewTrigger` | 'session-end' | session-end / idle（batch/turn-end 禁用） |
| `reviewRecentTurns` / `reviewMinResultChars` / `dedupeSimilarity` | 8 / 200 / 0.8 | review 参数 |
| `reviewProvider` / `reviewModel` | '' | 便宜模型（缺省不触发 review） |

## 六、已知非目标

1. **headless one-shot 下 review 不生效**：review 是 web/长驻特性；headless 一次性任务进程退出太快，后台 review job 无法完成。如需 headless 触发需装配 `dsh-tool-jobs` + 加「退出前等待 job settle」的有界关停，投入产出不成比例——**不做**。
2. **`batch`/`turn-end` review 触发**：默认禁用（D5/R5，高频 review 驱逐主会话 KV）。
3. **pending 审批门控**：D7 取消默认，未实现。

## 七、协作者交接（M1b USER 用户画像）

review 三路输出③已留 `userUpdates` 槽位，`MemoryStore` 已留 `userFile/userLimit/target='user'` 接口。协作者在 review 三路输出落地后按序：

1. 启用 `MemoryStore` user 槽位（`target='user'` 的 add/replace/remove）。
2. `SnapshotService` 追加 USER PROFILE 段（模板位置已在 M1 预留）。
3. 接通 review 三路输出③ → USER.md（只从用户本人消息抽取，格式：身份/偏好/目标/禁忌）。
4. 验收：用户画像跨会话注入、与 MEMORY 段字节一致、no-change 时零写入。
